# 自媒体创作工作台 — 开发文档

> 基于现有 multi-ai workbench2 技术栈（React 18 + reactflow v11 + Zustand + Tailwind + TypeScript + Chrome MV3）的自媒体模块开发方案。

---

## 1. 技术栈与约束

- **前端框架**：React 18 + Vite
- **状态管理**：Zustand（工作流 store 已存在）
- **画布**：reactflow v11
- **样式**：Tailwind CSS + 现有 `wb-*` 类（workbench）、CSS Modules（sidepanel）
- **存储**：`chrome.storage.local` + 内存缓存
- **并发控制**：`withStorageLock`（见 `src/shared/concurrency.ts`）
- **图标**：现有 `src/workbench/components/icons.tsx` 或 koboyo-icons MCP
- **图表**：优先轻量 SVG + 原生 canvas，避免引入 heavy chart 库（4GB 内存约束）

## 3. 数据层设计

### 3.1 Storage Keys
```ts
// src/shared/constants.ts
export const CREATOR_ACCOUNTS_KEY = 'multiAI.creator.accounts';
export const CREATOR_METRICS_KEY = 'multiAI.creator.metrics';
export const CREATOR_ASSETS_KEY = 'multiAI.creator.assets';
export const CREATOR_PLANS_KEY = 'multiAI.creator.plans';
```

### 3.2 accountStore.ts
复用 `customProviders.ts` 的「cache + storage + lock」模式：

```ts
let accountCache: Account[] | undefined;

export async function getAccounts(): Promise<Account[]> {
  if (accountCache) return accountCache;
  const res = await chrome.storage.local.get(CREATOR_ACCOUNTS_KEY);
  accountCache = (res[CREATOR_ACCOUNTS_KEY] as Account[]) ?? [];
  return accountCache;
}

export async function upsertAccount(account: Account): Promise<void> {
  await withStorageLock(CREATOR_ACCOUNTS_KEY, async () => {
    const list = await getAccounts();
    const idx = list.findIndex((a) => a.id === account.id);
    if (idx >= 0) list[idx] = account;
    else list.push(account);
    await chrome.storage.local.set({ [CREATOR_ACCOUNTS_KEY]: list });
    accountCache = list;
  });
}

export async function deleteAccount(id: string): Promise<void> { /* ... */ }
```

### 3.3 metricsStore.ts
- 写入：`addSnapshot(snapshot)` 追加快照。
- 读取：`getMetricsSeries(accountId, from, to)` 返回时间序列。
- 聚合：`getLatestSnapshot(accountId)` 用于卡片展示。

## 4. 新增节点类型

### 4.1 注册到 workflowStore
在 `workflowStore.ts` 的 `NODE_TYPES` / node registry 中加入：

```ts
accountMonitor: AccountMonitorNode,
topicMiner: TopicMinerNode,
articleWriter: ArticleWriterNode,
```

### 4.2 accountMonitor 节点
- **UI 配置项**：选择账号、时间范围（7/30/90/自定义）。
- **执行逻辑**：
  1. 从 `metricsStore` 读取指标序列。
  2. 若无数据或需要刷新，触发 background 同步。
  3. 输出 JSON：粉丝总量、增量、发帖量、趋势数组。
- **输出示例**：
  ```json
  {
    "accountId": "imwsi90-x",
    "followers": 96760,
    "followersChange7d": 337,
    "followersChange30d": 967,
    "posts": 81574,
    "series": [{"date":"2026-08-16","followers":95800}, ...]
  }
  ```

### 4.3 topicMiner 节点
- **输入**：`accountMonitor` 输出或手动输入账号数据。
- **UI 配置项**：热点关键词（可选）、输出数量、领域风格。
- **执行逻辑**：
  1. 组装 prompt：账号数据 + 历史爆款 + 热点词。
  2. 调用 AI（默认 qwen/chatgpt）生成选题列表。
  3. 输出结构化 JSON：标题、角度、预期平台、推荐理由。
- **prompt 模板位置**：`src/workbench/utils/creatorPrompts.ts`

### 4.4 articleWriter 节点
- **输入**：选题 JSON、大纲（可选）、参考素材。
- **UI 配置项**：字数、风格（严肃/轻松/爆款）、平台（公众号/知乎/头条）。
- **执行逻辑**：
  1. 拼接 prompt。
  2. 调用 AI 生成文章。
  3. 输出 markdown 正文。
  4. 自动保存为 `ContentAsset`（type='article', status='draft'）。

### 5.3 趋势图实现
不用 chart 库，用 SVG 绘制：

```tsx
function TrendChart({ series }: { series: MetricPoint[] }) {
  const width = 600, height = 160, padding = 20;
  const x = (i: number) => padding + (i / (series.length - 1)) * (width - 2 * padding);
  const y = (v: number) => height - padding - ((v - min) / (max - min)) * (height - 2 * padding);
  const path = series.map((p, i) => `${i === 0 ? 'M' : 'L'} ${x(i)} ${y(p.followers)}`).join(' ');
  return <svg viewBox={`0 0 ${width} ${height}`}><path d={path} fill="none" stroke="var(--accent)" strokeWidth="2"/></svg>;
}
```

## 9. 关键注意事项

1. **内存约束**：图表用 SVG，不用 chart.js/echarts；图片/视频素材只存 URL 或本地路径，不存 base64。
2. **存储上限**：`chrome.storage.local` 约 5-10MB；指标快照按日归档，超过 365 天可压缩或导出。
3. **平台抓取合规**：MVP 不自动抓取第三方平台后台；自动同步阶段只抓公开 API 或用户授权后的数据。
4. **origin 安全**：新增 background 消息类型需校验 `sender.origin`，沿用 `cd35960` 的校验模式。
5. **CRLF 行尾**：仓库使用 CRLF，新文件按仓库配置保持。
6. **每批提交验证**：每完成一个 Phase 跑 `npx tsc --noEmit && npx vite build`。
