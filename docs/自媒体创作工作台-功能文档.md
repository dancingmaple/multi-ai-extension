# 自媒体创作工作台 — 功能文档

> 依据 @imwsi90 账号监控截图设计，目标是把「账号数据监控」与「文章 / 图文 / 视频创作」纳入现有 multi-ai workbench 的 DAG 工作流。

---

## 1. 背景与目标

### 1.1 截图关键信息
- 账号：@imwsi90
- 粉丝：96,760（今天记的）
- 增长：近 7 天 +337，近 30 天 +967
- 发帖：81,574（关注 8,101，被 625 个列表收录）
- 趋势图：粉丝走势（30 天 / 90 天 / 全部）
- 二级模块：每天涨了多少
- 顶部动作：设置、同步

### 1.2 产品目标
把自媒体创作从「散点工具使用」升级为「数据驱动的工作流」：
1. **看数据**：聚合多平台账号核心指标，发现内容机会。
2. **定选题**：基于数据与热点生成选题池。
3. **产内容**：一键调用 chatgpt / qwen / deepseek 等 AI 生成文章 / 图文 / 视频脚本。
4. **发排期**：管理发布计划与多平台分发。
5. **做复盘**：回流发布后的互动数据，形成闭环。

---

## 2. 用户场景

| 场景 | 用户目标 | 工作台如何支持 |
|---|---|---|
| 日更前 | 看昨日涨粉/互动，决定今天写什么 | 打开「自媒体面板」，昨日数据卡片 + AI 选题建议节点 |
| 追热点 | 某话题爆了，快速产出文案 | 「热点捕获节点 → 选题节点 → 文案生成节点 → 人工审核节点」一键跑通 |
| 做系列 | 把爆款选题扩展成系列 | 「爆款解析节点 → 系列大纲节点 → 分集脚本节点 → 排期节点」 |
| 多平台分发 | 同一内容改写成不同平台风格 | 「原文节点 → 平台适配节点（公众号/小红书/抖音/视频号） → 发布队列节点」 |
| 周复盘 | 汇总一周数据，输出复盘报告 | 「数据抓取节点 → 数据分析节点 → 报告生成节点」 |

## 3. 功能模块

### 3.1 账号数据监控面板（自媒体面板）

对应截图，作为工作台左侧新增一级页面或右侧抽屉。

#### 3.1.1 账号看板
- **核心指标卡**：粉丝总量、近 7/30 天净增、发帖总量、日均互动（赞/藏/评/转）。
- **趋势图**：粉丝 / 阅读 / 互动 / 发帖量随时间曲线，支持 7 天 / 30 天 / 90 天 / 自定义。
- **增量明细**：「每天涨了多少」表格，支持导出 CSV。
- **账号列表**：支持添加多个平台账号（公众号、小红书、抖音、视频号、B 站、X 等）。

#### 3.1.2 数据源与同步
- **手动同步**：点「同步」按钮抓取最新数据。
- **自动同步**：按账号设置每日/每小时自动抓取（background alarm）。
- **数据导入**：支持粘贴平台后台数据、上传 CSV/Excel。

#### 3.1.3 内容资产库
- **我的内容**：历史文章 / 图文 / 视频脚本列表，按平台、标签、状态筛选。
- **爆款库**：标记高互动内容，作为后续仿写/拆解的素材。
- **素材库**：金句、案例、图片、视频片段、音乐（与「词语的河流」项目联动）。

---

### 3.2 创作工作流节点

在现有 reactflow DAG 中新增以下节点类型。

#### 3.2.1 数据类节点
| 节点 | 输入 | 输出 | 说明 |
|---|---|---|---|
| `accountMonitor` | 账号 ID、时间范围 | 指标 JSON | 抓取或读取账号数据 |
| `trendAnalyzer` | 指标 JSON | 趋势结论文本 | AI 分析涨粉/互动趋势 |
| `contentAudit` | 内容列表 | 爆款标签、低效内容标签 | 识别优质与待优化内容 |

#### 3.2.2 策划类节点
| 节点 | 输入 | 输出 | 说明 |
|---|---|---|---|
| `topicMiner` | 账号数据、热点关键词 | 选题列表 | 基于数据生成选题池 |
| `topicPicker` | 选题列表 | 确认选题 | 人工选择或 AI 打分排序 |
| `outlineGenerator` | 选题、风格、字数 | 大纲 | 生成文章 / 脚本大纲 |

#### 3.2.3 生产类节点
| 节点 | 输入 | 输出 | 说明 |
|---|---|---|---|
| `articleWriter` | 大纲、风格、参考素材 | 文章正文 | 长文生成 |
| `graphicWriter` | 选题、平台（小红书/抖音图文） | 图文脚本 + 配图建议 | 图文笔记生成 |
| `videoScriptWriter` | 选题、时长、口播风格 | 分镜脚本 + 口播稿 | 与「词语的河流」视频项目联动 |
| `titleGenerator` | 正文 / 脚本 | 多版本标题 | 平台适配的标题变体 |
| `platformAdapter` | 原文、目标平台 | 改写文案 | 一键改成小红书 / 公众号 / 抖音 / 视频号风格 |

#### 3.2.4 发布与复盘类节点
| 节点 | 输入 | 输出 | 说明 |
|---|---|---|---|
| `publishScheduler` | 内容、发布时间、平台 | 发布计划表 | 生成排期，可导出日历 |
| `distributor` | 内容、平台列表 | 各平台版本 | 多平台分发内容 |
| `postTracker` | 发布链接、时间窗口 | 互动数据 | 抓取发布后数据 |
| `reportGenerator` | 周期数据、发布记录 | 复盘报告 | 自然语言 + 图表 |

---

### 3.3 模板市场

- **系统模板**：爆款标题 100 式、小红书笔记模板、口播脚本模板、周复盘模板等。
- **用户模板**：用户保存自己的提示词模板，支持搜索、标签、一键填充到任意生成节点。
- **模板与工作流联动**：模板可作为节点的默认 prompt，也可被「提示词模板列表」组件调用。

---

### 3.4 创作看板

- **今日待办**：今日需发布 / 在审 / 待采集的内容。
- **排期日历**：按日/周/月查看发布计划。
- **数据预警**：连续 N 天掉粉、互动率低于阈值时高亮提醒。

## 4. 数据模型

```ts
interface Account {
  id: string;                 // 内部 ID
  platform: 'xiaohongshu' | 'wechat' | 'douyin' | 'shipinhao' | 'bilibili' | 'x' | 'custom';
  handle: string;             // @imwsi90
  displayName: string;
  profileUrl?: string;
  createdAt: number;
  syncConfig?: {
    enabled: boolean;
    intervalHours: number;
    lastSyncAt?: number;
  };

```

### 4.2 指标快照 MetricSnapshot
```ts
interface MetricSnapshot {
  accountId: string;
  recordedAt: number;         // 快照时间
  followers: number;
  following?: number;
  posts: number;
  likes?: number;
  comments?: number;
  shares?: number;
  collections?: number;       // 收藏
  views?: number;
  lists?: number;             // 被收录列表数

```

### 4.3 内容资产 ContentAsset
```ts
interface ContentAsset {
  id: string;
  accountId?: string;
  platform?: string;
  title: string;
  body: string;
  type: 'article' | 'graphic' | 'video_script' | 'idea';

  createdAt: number;
  publishedAt?: number;
  metrics?: Partial<MetricSnapshot>;
  isHit?: boolean;            // 是否标记为爆款
}
```

### 4.4 发布计划 PublishPlan
```ts
interface PublishPlan {
  id: string;

  scheduledAt: number;
```

## 6. 与现有功能结合

| 现有能力 | 结合方式 |
|---|---|
| AI 节点（chatgpt/qwen/deepseek） | 自媒体节点本质上仍是 AI 节点，只是 prompt 模板和输出格式固定为自媒体场景 |
| 提示词模板列表（v0.5 新增） | 自媒体模板单独成一个分类，在 articleWriter / graphicWriter / videoScriptWriter 中一键填充 |
| 内嵌执行（preferEmbed） | 生成节点仍可通过 iframe 打开对应 AI 平台，人工复核后点击继续 |
| 变量引用 `{{node_id.output}}` | 数据节点输出可作为下游生成节点的上下文变量 |
| 运行历史 | 一次完整创作流程（选题 → 大纲 → 成文 → 排期）作为一次 run 保存，便于复盘 |

## 7. MVP 范围（第一阶段）

为避免一次性铺太大，第一阶段聚焦「数据可看 + 文章/图文/视频脚本可生成」。

1. **账号数据面板**：支持手动录入/导入，展示 4 张核心卡片 + 粉丝趋势图。
2. **3 个新节点**：`accountMonitor`、`topicMiner`、`articleWriter`。
3. **自媒体模板分类**：在提示词模板列表中新增「自媒体」分类，含 5 个系统模板。
4. **运行与保存**：节点输出保存为 `ContentAsset`，状态为 draft。

第二阶段再扩展：自动同步、多平台适配、排期日历、发布后数据回流。

---

## 8. 验收标准

- [ ] 用户能在工作台打开「自媒体」页面，看到至少一个账号的数据卡片和趋势图。
- [ ] 用户能从「自媒体模板」一键填充 prompt 到 AI 生成节点。
- [ ] 用户能运行 `accountMonitor → topicMiner → articleWriter` 最小闭环，得到一篇文章草稿。
- [ ] 生成的内容自动进入「内容资产库」，状态为 draft，可二次编辑。
